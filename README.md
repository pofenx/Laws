本项目收集各类法律法规、部门规章、案例等，并将其按照章节等信息进行了处理。

## 应用

 - [LawRefBook](https://github.com/RanKKI/LawRefBook) 是原生 iOS 应用，使用 SwiftUI 构建。

## 贡献指南

### 手动贡献

 - 根据[法律法规模版](法律法规模版.md) 的格式，将法律法规放入 `法律法规` 文件夹下合适的位置
 - 在 `scripts` 目录下运行 `python database.py`（会自动更新 `sqlite` 内容）
 - 提交更改，并提 pr

### 自动脚本

`scripts` 目录下有一 `request.py` 脚本，支持从 [国家法律法规数据库](https://flk.npc.gov.cn) 爬取最新的法律法规。

在 `scripts` 目录下，执行以下指令

 - `python requessts.py` （脚本会自动处理，将新增法律加入列表以及合适的位置）
 - `python database.py` （会自动更新 `sqlite` 内容）
 - 提交更改，并提 pr

## 🔄 进行中的工作：官方原文持续采集（自动化更新）

> 本分支在原仓库基础上，持续追加**从官方来源重新采集**的法律法规原文。采集、复核、提交由自动化流程每日运行，本仓库将不断持续更新。

### 当前进展

- **官方原文库**（`official-data/`，附 `index.json`）：目前 **84 篇**（北京 20、江苏 20、上海 18、浙江 10、全国 9、湖南 4、山东 3）。每篇注明来源官网 URL、属地、发布机构、效力状态与 SHA-256；效力状态未经权威证据核验前一律标「待核验」，不标「有效/废止」。
- **采集器**（`official-collectors/`）：有界、限速的独立脚本与 `status.py` 统计工具，每日定时增量运行。
- **候选来源调研**（`official-collectors/research/`）：全国 31 个省级行政区官方法规库入口清单，持续验证接入中。

### 说明

- 官方原文（`official-data/`）与原仓库第三方整理文本相互独立、分目录存放，不混淆来源。
- 数据仅供学习研究，不构成法律意见；引用请以官方公布为准。
